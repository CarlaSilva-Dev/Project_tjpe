Sistema web MVC com Flask (Python). O front-end usa templates Jinja2 com HTML/CSS. O banco é SQLite. Geração de PDFs via WeasyPrint. Deploy containerizado com Docker.

  • CRUD de processos
  • CRUD de relatórios
  • Acesso à auditoria
  • Gerenciar sistema
  • Gerar PDFs

🔵 Servidor

  • Cadastrar processos
  • Editar processos
  • Criar relatórios
  • Visualizar dashboard
  • Gerar PDFs

🟢 Magistrado

  • Visualizar processos
  • Visualizar relatórios
  • Dashboard (leitura)
  • Gerar PDFs
📄 Módulo: Processos

Núcleo do sistema. Gerencia todos os processos de Usucapião cadastrados no TJPE.

Listar Criar Editar Excluir Detalhar Buscar Filtrar Gerar PDF

Campos: número, autor, réu, comarca, tipo de usucapião, status e observações.

📊 Módulo: Relatórios

Criação de relatórios filtrados por comarca, tipo de usucapião e status dos processos.

Listar Novo Editar Excluir Visualizar Exportar PDF

Vinculado ao usuário criador (FK usuario_id). Permite filtros avançados por período e comarca.

👤 Módulo: Usuários

Gerenciamento dos usuários do sistema com controle de perfis e acesso.

Listar Criar Editar Excluir

Autenticação com hash SHA-256. Três perfis: Administrador, Servidor, Magistrado. Login com sessão Flask.

🔍 Módulo: Auditoria

Rastreamento de todas as ações realizadas no sistema para fins de segurança e conformidade.

Visualizar logs Filtrar Registrar ação

Registra automaticamente ações como criação, edição e exclusão de processos e usuários, com data/hora e usuário responsável.

📈 Dashboard / Painel Principal

Visão geral do sistema com indicadores de processos por status, comarca e tipo de usucapião. Exibe totais, gráficos e acesso rápido às principais funcionalidades. Acessível para todos os perfis.

Requisitos do Sistema

Levantados a partir do código-fonte do repositório Project_tjpe

✅ Requisitos Funcionais — Processos
  • RF01 Cadastrar processo com número, autor, réu, comarca, tipo e status
  • RF02 Listar todos os processos com paginação e busca
  • RF03 Editar dados de um processo existente
  • RF04 Excluir processo (com registro em auditoria)
  • RF05 Visualizar detalhes completos de um processo
  • RF06 Gerar PDF individual de processo
  • RF07 Gerar relatório PDF de todos os processos
  • RF08 Filtrar processos por comarca, status e tipo
✅ Requisitos Funcionais — Usuários
  • RF09 Realizar login com email e senha
  • RF10 Realizar logout encerrando a sessão
  • RF11 Cadastrar novo usuário (apenas Admin)
  • RF12 Editar dados do usuário
  • RF13 Excluir usuário
  • RF14 Atribuir perfil: Administrador, Servidor ou Magistrado
  • RF15 Bloquear acesso a rotas por perfil insuficiente
✅ Requisitos Funcionais — Auditoria e Relatórios
  • RF16 Registrar automaticamente ações dos usuários
  • RF17 Listar e filtrar logs de auditoria
  • RF18 Criar relatórios personalizados filtrados
  • RF19 Editar e excluir relatórios
  • RF20 Visualizar relatório com dados atualizados
  • RF21 Exportar relatório em PDF
🔒 Requisitos Não-Funcionais
  • RNF01 Senhas armazenadas com hash SHA-256
  • RNF02 Controle de sessão com Flask-Session
  • RNF03 Validação de email e força de senha
  • RNF04 Sistema deve ser executável via Docker
  • RNF05 Interface responsiva e acessível via navegador
  • RNF06 PDFs gerados com layout institucional TJPE
  • RNF07 Banco de dados SQLite sem dependências externas
  • RNF08 Seed de dados para testes (100 processos)
